# ACADEMIC_pub

Replication materials for published academic research by Jacob S. Bower-Bir.

## Published Papers

| Paper | Journal | Year | Data | Code |
|---|---|---|---|---|
| [Desert and Redistribution](desert-redistribution-psj-2021/) | *Policy Studies Journal* 50(4) | 2022 | In the package (27 columns) | R, Python; original Stata |
| [Earning Our Place, More or Less](earning-our-place-ecopol-2020/) | *Economia Politica* 38(1) | 2021 | In the package (54 columns) | R, Python; original Stata and R |

Each folder is a replication package, as deposited in IU DataCORE: the data the paper uses, with a codebook; scripts in R and Python that reproduce every table and figure; the tables as published, with typos fixed, and re-estimated on the corrected data; the figures; and a README. Both articles contain published errors, listed in each README's Summary. Read it before citing a number from either article.

## Shared Data

The [Economic Justice Survey (v7)](data/) supports both papers: 992 records (991 respondents), weighted to national population totals. The full survey (the raw data, the cleaning scripts, the instrument, a codebook, and a provenance record) is being deposited at IU DataCORE and is not in this repository. Each paper's folder holds the columns that paper uses.
